# Elektryk Majkel

Strona wizytówkowa usług elektrycznych dla lokalnego biznesu w **Radomyślu nad Sanem**.

**Live:** [elektryk-majkel.vercel.app](https://elektryk-majkel.vercel.app)

## Stack

- Next.js 16 + React 19 + TypeScript
- Tailwind CSS 4
- Sanity CMS (treści / media)
- Leaflet (mapa obszaru działania)
- Nodemailer (formularz kontaktowy)
- Deploy: Vercel

## Funkcje

- sekcje usług i uprawnień SEP
- responsywny UI
- CMS do edycji treści bez ruszania kodu
- formularz wyceny / kontaktu
- optymalizacja obrazów

## Start lokalnie

```bash
npm install
npm run dev
```

Otwórz [http://localhost:3000](http://localhost:3000).
